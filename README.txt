MMGM Collection Website

Files:
- index.html: your website homepage
- robots.txt and sitemap.xml: basic search-engine files

To publish free with GitHub Pages:
1. Open your GitHub repository.
2. Tap Add file, then Upload files.
3. Upload index.html, robots.txt, and sitemap.xml.
4. Commit changes.
5. Open Settings > Pages and enable deployment from the main branch / root folder.

Your website address depends on your GitHub repository name.
If the repository is mrmuzamilkhan83.github.io, the address is:
https://mrmuzamilkhan83.github.io/

For another repository name, the address is:
https://mrmuzamilkhan83.github.io/REPOSITORY-NAME/
